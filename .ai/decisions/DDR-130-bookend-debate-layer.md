# DDR-130: Bookend debate layer — native agent-teams debate at the flow/design loop's start + end, with a reduce-pass floor and eval-first rollout

- **Date:** 2026-06-25
- **Status:** Accepted (implementing — `.ai/plans/feature-orchestration-layer.md`)
- **Tags:** flow, design, orchestration, agent-teams, debate, subagents, capability-gating, eval-first, project-agnostic, cast-by-stake
- **Related:** [DDR-004](./DDR-004-flow-command-naming-prefix-convention.md) + [DDR-006](./DDR-006-plugin-namespace-in-name-frontmatter.md) (the new agents declare `name: flow:<slug>`), [DDR-127](./DDR-127-showcase-grounded-canvas-generation.md) (the "markdown plugin-spec change, no code gates" validation precedent this mirrors). Spec: `.ai/plans/feature-orchestration-layer.md`; `plugins/flow/.claude-plugin/config.schema.json` (`orchestration` block); `plugins/flow/skills/debate-protocol/SKILL.md`; `plugins/flow/agents/{builder,shipper,breaker,user-advocate,investigator}.md`; `plugins/flow/commands/validate-security.md`; `plugins/design/commands/critic.md`.

## Context

Maude's 21 agents are almost entirely **critics** — convergent, "absence-of-badness," each emitting an independent JSON verdict that an orchestrator *sums*. There is no **divergent** capability (propose competing directions), no **adversarial** capability (a seat whose win-condition is the artifact *failing*), and no **research** capability (compete hypotheses, end on evidence). Critics also never *revise a stance after hearing another* — so the system can only do set-arithmetic over fixed verdicts; it cannot surface the *conditional* form of a constraint ("the contrast floor only binds on the text band, so the bold hero can stay").

The user's framing: in the human loop `brainstorm → plan → execute → validate → done`, multi-perspective debate pays most at the **bookends** — divergent at the start (what/how), adversarial at the end (is it safe/done/good) — and in **research**; the middle (`execute`) is solo. They want this built on **native Claude Code agent teams** with **no custom orchestration layer**, and applied to make the flow + design plugins more precise.

The native ground truth (docs): agent teams are **experimental, off-by-default** (`CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`), **cannot be force-enabled by a plugin**, are **lead-spawned via natural language** (no deterministic API), let teammates **message each other + share a task list**, **reuse subagent `.md` defs** as roles (`tools`+`model` honored, body appended; `skills`/`mcpServers` NOT applied to a teammate), cost tokens **linearly per seat**, and are named in the docs as the #1 use case for "research and review … scientific debate … disprove each other's theories … consensus."

## Decision

Add an **additive, capability-gated, auto-at-the-bookends debate layer** with a strict two-tier ladder, built only on native primitives.

1. **Bookend model.** Debate fires only at the loop's bookends + research; `execute` stays solo. **START** = DIVERGENT ("what's BEST", no artifact) on `/flow:plan`, `/flow:setup-prd`, `/design:setup-ds`. **END** = ADVERSARIAL ("is it actually safe/done/good", artifact exists) on `/flow:validate-security`, `/design:critic`. **RESEARCH** = "what's TRUE", ends when evidence *eliminates hypotheses* (not when voices agree) on `/flow:bug-rca`, `ux-research`. `/flow:quick` gets only an escalate-only tripwire (the dangerous change is the one that looks trivial).

2. **Two-tier capability ladder — `reduce` vs `relay`.** The ONLY thing a live team adds over today's panel is **stance revision**. That draws the load-bearing line:
   - **`reduce` (default, every user, flag-off, cheap):** a consolidator **reads** the N finished verdict JSONs and resolves contradictions into one ordered list. Read-only over outputs.
   - **`relay` (flag-on, premium, native teams only):** the experimental runtime carries messages so a seat can revise after hearing another.
   - **One-line test:** does the step only *read finished verdicts* (`reduce`, allowed) or *route one agent's words into another agent's input and iterate* (`relay`)? **We NEVER hand-roll relay in markdown** — the moment a critique becomes another critique's prompt in our own code, we have built the team simulator we refuse to build. Flag-off ⇒ `reduce` only; `relay` is 100% native teams. We ship **no** `.workflow.mjs` and **no** messaging engine.

3. **`orchestration.mode: auto`, honest downstream.** `auto` = `relay` if the experimental flag is detected, else `reduce`; AND the stakes-gate clears; AND the short-circuit found a fork. The plugin **never force-enables the flag** and **never spends premium tokens the user didn't authorize**. For ~every downstream user the flag is off, so `auto` means exactly today's behavior plus the cheap reduce-pass — nothing to configure, no nag. `default:true` is therefore honest. Flow seats carry **no Maude-specifics** (project-agnostic); design seats MAY be Maude-flavored (intended asymmetry).

4. **Two gates keep "always auto" from being "always expensive."** (a) **Stakes-gate** (pre-debate): reversibility × blast-radius × effort; below floor → solo-decide; team SIZE scales with cost-of-being-wrong, cap 2–4. (b) **Short-circuit** (post-blind-opening): seats open *blind* (independent contexts); escalate to a full debate ONLY on genuine disagreement; agreement → "converged, decided," cost ≈ one reduce-pass. The escalation rate is **observable** — >~50% means openings aren't independent enough; re-tune.

5. **Cast by stake; personality is the voice; merge the hats.** A chair is earned ONLY by an orthogonal failure-mode no seated chair owns. **Personality is the delivery vehicle (conviction), the stake is the cargo — no cargo, no seat.** Standing seats (stakes): `flow:builder` (premature convergence), `flow:shipper` (hidden cost), `flow:breaker` (breaks, incl. the maintenance horizon — absorbs Sisyphus), `flow:user-advocate` (wrong thing / who's excluded), `flow:investigator` (not true) — **5 net-new** — plus reused `ethical-hacker` (ATTACKER), `security-auditor` (DEFENDER), and the 13 design critics. **Falsifiable merge-test:** log each seat's binary `verdict` across N runs; if two seats agree >~90%, they are one seat in two hats — merge them. A forced dissenter that flips ~100% is also theater.

6. **Archetype dispositions** (recorded so they don't get re-proposed): naive junior → BUILDER voice / conditional internal-legibility seat (build+design only); grump/morous → BREAKER+DEFENDER voice ("regression-risk skeptic", auditable, not a mood); **devil's advocate → mandatory ROTATING dissent on the non-proposer, not a chair**; **Sisyphus → BREAKER maintenance-horizon lens** (no decision found where TCO flips a call BREAKER+SHIPPER jointly miss); **historian → RETRIEVAL STEP** (grep relevant DDRs/retros into the opening prompt — it supplies priors all seats reason from, it never contradicts a verdict, so it is not a debater); customer → USER-ADVOCATE voice; zealot/minimalist → voices, not chairs.

7. **Eval-first governance.** Live debate rides an experimental feature and costs linear tokens, so we prove it before turning it on broadly. The **`reduce` floor ships to everyone immediately** (a pure win — `/design:critic` consolidation moves from "sum of blockers" to one reconciled list). `relay` is proven on the one bookend with crisp ground truth — **security** — via an **n=8 eval**: corpus of 8 past auth/input/network changes (4 with a seeded known finding, 4 clean); arm B = today's parallel pair + reduce; arm C = the 2-turn attacker↔defender debate; objective 2×2 (detection + false-positive, no human judge). **Ship rule: keep/expand `relay` only if C raises detection OR cuts false-positives vs B; a tie kills it even for security.** Design gets NO debate-vs-panel eval (no seedable ground truth) — that absence is itself the argument design stays `reduce`; a `/design:critic` live team is separately gated on measured ≥30% conflict-oscillation in the instrumented `/design:edit --perfect` loop AND a reduce-pass demonstrably failing.

## Consequences

- **New mental model: the flow loop has debate bookends.** START diverges, END adversarially validates, RESEARCH eliminates hypotheses, EXECUTE stays solo. CLAUDE.md gains a pointer; the spec is the plan + this DDR.
- **Net-new agents: 5** (`builder`, `shipper`, `breaker`, `user-advocate`, `investigator`), each reusable BOTH as a report-back subagent (`reduce`) and a live teammate (`relay`) unchanged. Plus one shared `flow:debate-protocol` skill (the mechanism) and one `orchestration` config block. "Promote, don't proliferate" — every brainstormed archetype resolved to a voice, the rotating role, a retrieval step, or a reuse.
- **No custom runtime.** Drops the prior plan's `.workflow.mjs`. `relay` = native teams; `reduce` = parallel subagents + a read-only consolidator. The reduce-vs-relay line is the permanent guardrail against re-implementing SendMessage in markdown.
- **Additive / off → unchanged.** With the experimental flag off and `mode` absent, behavior is today's plus the reduce-pass; `mode:off` restores raw sum-of-verdicts byte-for-byte. The `orchestration` block is opt-in (not in `required`).
- **Pilot scope.** This plan ships the floor + config + cast + the `flow:debate-protocol` skill + the `/flow:validate-security` proving ground + the eval; the broad `mode:auto` rollout (plan/setup-prd/setup-ds START, bug-rca/ux-research RESEARCH, quick tripwire, design-team) is enumerated as follow-up, gated on the eval clearing.

## Alternatives considered

- **Custom dynamic-workflow script (`/flow:plan --deep`, the prior plan).** Rejected: plugin-shipped `.workflow.mjs` loading via `scriptPath` is unproven, and the workflow's off-context benefit is moot for most users (flag-off). A workflow also can't take mid-run input and adds a runtime to maintain for one consumer. The bookend/native-teams model subsumes it; the surviving idea (one batched post-debate `AskUserQuestion`) is kept.
- **Hand-rolled relay when the flag is off** (feed critic A's verdict into critic B). Rejected as the explicit REFUSE side of the reduce-vs-relay line: re-implements SendMessage + the shared task list in markdown, badly, with none of the runtime's guarantees, and violates "no custom layer."
- **Rich personality cast (naive junior / grump / Sisyphus as standing chairs).** Rejected as standing seats: same-model personas share a prior, so distinct *vibes* produce tonal variance with zero verdict variance (theater). Kept as *voices* on stake-seats; only orthogonal objectives earn chairs (the merge-test enforces it).
- **Auto-debate on every command, including `execute`/`quick`/per-iteration loops.** Rejected: linear token cost on latency-sensitive, fork-free work. Debate is bookends-only; `quick` gets an escalate-only tripwire; `execute` stays solo.
- **Rare + explicit `--debate` only (the first panel's conclusion).** Superseded by the user's bookend framing: invoking a bookend command IS the stakes-gate, and the short-circuit makes "always auto" cheap on agreement — so `auto` beats opt-in, gated by the two gates + capability detection.
