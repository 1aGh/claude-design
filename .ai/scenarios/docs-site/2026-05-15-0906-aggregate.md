## Top follow-ups (prioritized)

### Real bugs (DS-spec deviations)

1. **Numbered h2 counter rule not applied.** `getComputedStyle(h2, '::before').content` returns `"none"` on `/docs/design/bootstrap` for all 5 h2s on both viewports. The `counter-reset: mdcc-h2` / `counter-increment` / `::before { content: counter(mdcc-h2, decimal-leading-zero) }` rule from plan Task 9 either never landed or is scoped to a class the live DOM doesn't carry. Audit `site/app/global.css` `.prose` block. **DS-03 spec deviation.**

2. **Mobile theme toggle unreachable.** `button[aria-label="Toggle Theme"]` exists in the DOM but `getBoundingClientRect() = {0,0,0,0}`, `offsetParent = null` at 375px viewport. Opening the mobile sidebar does not surface a second instance. Clicking has no effect (no `.dark` toggle, no `localStorage.theme` write). End-user impact: mobile users cannot switch themes.

3. **cmd-K dialog uses `backdrop-filter: blur(4px)`** in the inner Radix overlay. DDR-011 paper/phosphor aesthetic forbids glassmorphic blur. Should be solid dim (e.g. `rgba(0,0,0,0.5)`).

### DS-acknowledged degradations (DDR-011 fallback paths)

4. **Lucide `<svg>` icons inside cmd-K result rows** — `lucide-chevron-right`, `lucide-hash` (16 total inside `[role=dialog]`). The spec's "DDR-011 fallback" footnote acknowledges this when Orama doesn't expose `result.type`. Confirm whether the latest fumadocs surfaces `result.type` so the MDCC glyph prefix (`▸ / ● / ○`) can be enabled.

5. **4 Lucide `<svg>` inside `#nd-sidebar a`** — all in auxiliary external-link items (Source, Buy me a coffee). Zero on docs-tree items. Borderline against the DDR-011 hard-NO rule: the rule targets docs-tree sidebar nav, external-link affordances are arguably a different category. Decision: (a) clarify DDR-011 scope, or (b) replace with ASCII glyphs.

### Spec / runner drifts (no product impact)

6. **landing-first-visit spec mentions `.landing-hero h1` and "3 code lines"** — actual DOM uses `.mdcc-hero h1` and the InstallSnippet `<pre>` has 8 lines. Update spec selector + count.

7. **deep-read-prose-flow spec uses `[data-toc]` selector** — fumadocs renders the TOC into `#nd-toc`. Update spec selector.

8. **deep-read-prose-flow mobile pager click landed on `/docs/design`** (category index) instead of `/docs/design/multi-ds`. Likely click-target collision at narrow viewport — `agent-browser`'s selector tightening, not a routing bug. Desktop click works correctly.
