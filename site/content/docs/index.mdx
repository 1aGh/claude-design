A Claude Code marketplace by Michal Dovrtěl. Two plugins. One CLI. One version. The repo is the source of truth — decisions, plans, design mocks, retros all live next to the code they belong to.

- **`design`** — canvas-first iteration on HTML / JSX mocks under `.design/`. Zero-dep dev server. Cmd+Click inspector overlay so Claude knows which element the feedback is about.
- **`flow`** — generic agentic workflow loop with a second-brain `.ai/` workspace. Project-agnostic via per-repo `workflows.config.json`. Same plugin runs in Next.js, Expo, Go, anything.
- **`mdcc`** — small CLI. Scaffolds the `.ai/` workspace, reads / writes config, boots the design dev server.

Open-source. MIT. No telemetry, no signup, no _book a demo_ button. If it crashes, `git pull` and try again — that's the entire support contract.

## Why both plugins together?

The two plugins share a worldview: **Claude Code is the IDE; the repo is the source of truth.** Decisions get written to `.ai/decisions/`. Plans get archived to `.ai/plans/archive/`. Design mocks live in `.design/` next to the production code they precede. Nothing lives only in a chat scroll.

Install one, install both. The marketplace doesn't care which.
