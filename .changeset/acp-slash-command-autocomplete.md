Slash-command autocomplete + inline highlight in the native Assistant chat composer. Typing `/` opens a filter-as-you-type menu of the design and flow commands your `claude` actually has installed (keyboard- and mouse-selectable), and a recognized command lights up as a pill right inside the input — so you don't have to remember which commands exist. The command list comes live from your own Claude session (with a built-in bootstrap list for instant suggestions).
