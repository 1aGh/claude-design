tokens / motion

Motion

Four durations, three easings, one playful spring. Zed-fast on chrome — 120ms — because slow chrome feels broken. Affinity-luxurious on signature moments — 420ms ambient pulse — because brand needs breathing room. Hover any tile below to feel the difference.

Durations

--dur-flip · 120ms

Button hover, segmented toggle, link underline. Almost instant — chrome doesn't apologize for being there.

--dur-panel · 220ms

Sidebar reveal, popover open, dialog enter. Fast enough to feel responsive; slow enough to register.

--dur-route · 280ms

Screen swap, route transition. The view's job is changing — give the user a beat to track it.

--dur-soft · 420ms

Ambient glow pulse, presence cursor settle, signature moment. Affinity-territory — used sparingly.

Easings

--ease-out
--ease-in-out
--ease-spring

default = ease-out. ease-in-out for symmetric motion (toggle, modal). ease-spring for ONE playful moment per surface, max.

Reduced motion

Every duration collapses to 1ms when the user has prefers-reduced-motion: reduce set. Test it in DevTools → Rendering. The ambient pulse keeps cycling but at human-imperceptible speed.

One spring curve per surface. Two springs means the surface is showing off; three means it's nervous.

Never use a magic number. Every transition / animation references var(--dur-*) + var(--ease-*). The completeness-critic V19 will catch raw 120ms in scaffolded files.
