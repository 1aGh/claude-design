Callout

Inline boxes used in long-form docs. Five flavors — info, note, warn, success, and a brand-amber variant reserved for hero/landing content. Eyebrow is mono; body is sans; the left border carries the hue.

→

info

studio runs as a local dev-server. There's no cloud component, no telemetry, no account. Your .design/ directory is the source of truth.

note

Cmd-click any element in a canvas iframe to scope the next /design:edit to that element. The inspector overlay highlights what the next edit will target.

warn

Don't reach for --accent2. The one-accent rule prevents drift; if you find yourself needing a parallel accent, the answer is --brand-amber on a marketing surface, not in chrome.

passed

studio principle

Iterate against the artifact, not the abstraction. Looking at the live mock is faster than arguing about specs. studio's whole shape is built around that bias.

The brand callout is reserved for docs-landing and the studio README. Don't ship it in dev-server chrome — that's exactly the kind of amber leak the chrome rule prevents.
