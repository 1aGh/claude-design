components / toggles

Toggles

Four shapes, one anatomy thesis — recessed bay, raised chip on active. Switch (settings), checkbox (multi-select), radio (mutual exclusion), segmented (view modes). All four use --accent with glow on the "on" state.

Switch

Chunky hardware toggle — recessed track + raised thumb with gradient highlight. The thumb literally moves left→right; the track lights plasma when on.

Checkbox

Recessed square bay → plasma slab with white check on activation. Indeterminate state shows a phosphor minus instead of the check.

Radio

Recessed disc → plasma inner with glow. Inset ring rather than outer border to keep the field flat.

Segmented

Recessed bay with the active button raised + plasma fill + accent glow. Unselected buttons sit flush with the floor.

Don't mix switch and checkbox in the same group — switches are stateful settings, checkboxes are batch selections. Different jobs, different shapes.

Segmented is for ≤ 4 mutually exclusive options. Beyond that, use a select or tabs — packing 5+ chips into a segmented breaks the affordance.
