components / toggles

Toggles

Four shapes, one anatomy thesis — recessed bay, raised chip on active. Switch (settings), checkbox (multi-select), radio (mutual exclusion), segmented (view modes). All four use --accent with glow on the "on" state.

Switch

Recessed track + raised thumb. The thumb moves left→right; the track flips to plasma when on. No glow, no gradient — the state change is the signal.

Checkbox

20px raised tile on --bg-3 with a visible border, so the unchecked state reads on any parent surface. Solid plasma fill with a bold check on activation. Indeterminate shows a white minus.

Radio

20px raised disc. Plasma border on the track plus a solid plasma inner dot signal selection — no halo, no inner gradient.

Segmented

Recessed bay with the active button raised on a 1px rim of plasma. Unselected buttons sit flush with the floor — selection is the only state change.

Don't mix switch and checkbox in the same group — switches are stateful settings, checkboxes are batch selections. Different jobs, different shapes.

Segmented is for ≤ 4 mutually exclusive options. Beyond that, use a select or tabs — packing 5+ chips into a segmented breaks the affordance.
