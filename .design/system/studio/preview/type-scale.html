Display vs body — when to switch

Use var(--font-display) at every --type-lg and above, with --tracking-display. Use var(--font-body) at --type-md and below, no extra tracking. The mono is reserved for kbd, code, file paths, status bar — never long-form.

The 8 steps + 1 display is not arbitrary. Skip rungs: --type-base → --type-md → --type-lg → --type-2xl → --type-3xl is a typical hero card. Adjacent rungs (--type-base next to --type-sm) read as one rank, not two.
