Keyboard

kbd is mono, slightly raised (2px bottom border), and uses the symbol set — ⌘ not "Cmd", ↵ not "Enter", ⌫ not "Backspace".

Don't mix sentence-case and symbol forms. ⌘K is correct; "Cmd+K" is not. The symbol is the kbd.
