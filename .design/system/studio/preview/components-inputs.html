Select

Don't pair a sans label with a mono input. The whole field reads as chrome — keep the type discipline.

Inputs at 7px vertical padding; buttons next to inputs at 6px vertical padding (same effective height after the button's border). Mismatch is visible and ugly.

Recessed feel comes from inset 0 2px 4px oklch(0% 0 0 / 0.50) + a 2% darker base. Don't flatten this — the input is supposed to look pressed-in, not raised.
