Mono

Geist Mono is a display surface, not a code-block-only typeface. It carries every status bar, file path, port number, kbd, and version label in studio. Where most DSes default to sans, the dev-server defaults to mono — chrome lives in mono, content lives in Geist.

The studio house voice is mono. Use sans (--font-body) for long-form reading and primary UI labels; use mono for everything that names a thing — paths, ports, dates, version labels, code, kbd, status text.
