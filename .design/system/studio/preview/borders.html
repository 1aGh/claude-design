Borders

Three border tiers derived from --bg-1 via oklch(from var(--bg-1) calc(l + N) c h). The derivation tracks the surface so the chrome stays coherent if the theme shifts.

--border-subtle+0.04 L · row dividers, nested separators
--border-default+0.08 L · card, input, chip, panel
--border-strong+0.14 L · focused panel, hover

Don't add a 4th tier. If a border needs to stand out more, reach for --accent on the border-color, not a new --border-* token.
