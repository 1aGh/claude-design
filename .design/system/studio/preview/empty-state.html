Voice — keep or kill

keep

"No canvases in this project yet. Start with /design:new."

Names the thing. Offers a verb. Mono command makes the next step concrete.

kill

"Welcome to studio! Looks like there's nothing here. Get started by creating something!"

Three exclamation marks. Two filler clauses. Names nothing. The reader has to guess what "something" means.

Empty-state copy survives years. Spend the time to write a real sentence: "Log your first match" beats "Get started" every time.

If the missing thing is a list, use a singular noun ("No canvases yet"). If it's a search result, quote the query ("No matches for 'plasma button'"). Always say what's missing — never start with "Nothing here".
