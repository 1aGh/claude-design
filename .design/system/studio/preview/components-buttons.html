Buttons

Four variants — primary (plasma slab with LED), secondary (sunken hardware bay), ghost (wire-frame), destructive (error-tinted primary). Anatomy is chunky 3D bevel: top highlight + bottom shadow + outer drop. Lowercase mono labels — the button label IS chrome, not content.

Hierarchy

Sizes

btn--sm · btn (default) · btn--lg — radius scales with size; type goes 11 → 12 → 13

States

idle hover disabled loading primary secondary ghost — destructive

Icon-only

Icon-only buttons are 32×32 hardware keys. Always include an aria-label.

With kbd hint

Pair a button with its keyboard shortcut. The kbd sits inside the button after the label.

Anatomy

  • ▸ top highlight · inset 0 1px 0 oklch(100% 0 0 / 0.30)
  • ▸ bottom inset · inset 0 -1px 0 oklch(0% 0 0 / 0.25)
  • ▸ rim · 0 2px 0 oklch(from var(--accent) calc(l - 0.22) c h)
  • ▸ outer drop · 0 4px 12px oklch(0% 0 0 / 0.45)
  • ▸ press · translateY(2px) on :active — drop collapses
  • ▸ LED · 6px white phosphor — primary CTAs only

The LED dot (.icon-led) is reserved for primary CTAs only. It's a "power-on" indicator — slapping it on a secondary button cheapens the signal.

Lowercase labels are not optional. "save" beats "Save" — terminal cadence is the studio house voice. Capitalize only proper nouns inside button labels.

Press animation (translateY +2px on :active) is part of the anatomy. A button that doesn't press doesn't feel like a button.
