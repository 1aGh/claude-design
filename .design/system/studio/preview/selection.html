Selection

Studio's selection styling uses --accent at 30% alpha for the background and --fg-0 for text. Try it — select any text on this page.

Plasma carries every clickable surface in studio. Amber is reserved for moments. When you find yourself reaching for amber inside a button, you've already lost the argument.

Common selections in the dev-server: file paths (.design/system/studio/colors_and_type.css), token names (--accent-soft), kbd combos (⌘K).

--accent: oklch(68% 0.22 285); --accent-fg: oklch(14% 0.040 285); --brand-amber: oklch(64% 0.18 50);

Pre-selected example

For agents that can't synthesize a real selection, this paragraph contains a pre-highlighted span showing the active selection appearance.

Don't override ::selection on a per-component basis. The selection style is a project-wide agreement — overriding it inside a code block makes copy-paste feel like a different app for two seconds.
