Surfaces

Five steps from page (--bg-0) to active state (--bg-4). The lightness gap is tight on purpose — studio's elevation reads through borders and shadows, not through dramatic bg jumps. Affinity does this; PostHog does this; we do this.

Borders

Borders derive from --bg-1 using oklch(from … calc(l + 0.04 / 0.08 / 0.14) c h). They track the surface so chrome stays coherent if you swap theme.
