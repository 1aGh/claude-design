Grid

The desktop shell skeleton: 56px top nav · 248px sidebar · fluid main · 28px status bar. Every screen in the dev-server fits this grid. Tokens for each dimension live in colors_and_type.css.

nav · --layout-nav-h · 56
sidebar · --layout-sidebar-w · 248
main · fluid · max-w 1280
status · --layout-status-h · 28
nav 56px sidebar 248px main max-w 1280px · gutter 16 status 28px

Don't change these on a per-screen basis. The grid is the agreement — sidebar always 248px so a returning user's muscle memory survives.
