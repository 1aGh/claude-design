# v4 references — note on scope

The plan's Phase A.1–A.3 called for an 8–12 reference research pool to
*derive* the visual vocabulary. In practice the user made the look call
directly and up front (4-axis decision pass, 2026-06-08): **render in the
maude product chrome** (the real DS), full real-loop narrative, voice-aligned
captions, rhythm-decided length. That decision supersedes the
reference-pool-derives-the-look step — the DS *is* the look, and it is
already designed and shipped (`.design/system/maude/`).

What references still inform is the **motion vocabulary** (not the palette,
which is settled). Touchstones we want to steal *motion ideas* from — and
the one thing we won't copy:

| Reference | Steal | Won't copy |
|---|---|---|
| Linear (launch films) | Restraint; one idea per frame; hard cuts; type confidence | Their exact gradient-on-black wash (we have the dotted canvas instead) |
| Bun (site/launch) | Kinetic terminal typing as a hero beat | Mascot whimsy / playful bounce |
| Vercel (product reels) | Live "fill the surface" reveals; split-screen code↔result | Heavy saturation / neon glow |
| Raycast | Command-palette + keyboard-affordance moments; calm dark UI | Skeuomorphic depth |
| Arc | Cursor-as-character; presence/personality in a pointer | Teaser-without-substance pacing |

The hard-NO list lives in `_brief.md`. If a later scene wants to pull a
catalog-motif element back in, it must re-defend it against this note — it
is not a default.
